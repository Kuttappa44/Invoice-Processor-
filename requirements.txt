#   - Supports both Azure OpenAI and regular OpenAI

#
# Azure Blob Storage:
#   - Used for storing uploaded PDF files organized by vendor folders

#

#   - Used for Excel file management and sharing
#   - Requires ENABLE_GOOGLE_DRIVE_UPLOAD=true and OAuth credentials
